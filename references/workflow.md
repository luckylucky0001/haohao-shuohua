# 成稿流程

随手一两句的回复，心里过一遍原则就行，不用走这里。要对外发布或存档的成稿（文档、文章、公告、长邮件、报告），按下面的顺序走。

## 目录

1. 动手前：认场合、定尺度、锁保护项
2. 改写：从含义出发
3. 三遍回读
4. 机器扫描
5. 交付：正文、提醒、修改报告
6. 出稿前自检清单

---

## 1. 动手前

**认场合。** 用户说了场合（“这是给客户的”“发朋友圈”“对外公告”）就照他说的；没说就从上下文判断，归到官方对外、敬语、要气势、私人随手、技术议论五类之一；实在判断不了，带一个默认值问一句。

**定尺度和力度。** 让你改一篇就是文章级，改一段就是段落级。力度默认标准档；用户说“大改”“重写”是重改，说“别大改”“只挑最刺眼的”是轻改。

| 力度 | 能动什么 | 不能动什么 |
|---|---|---|
| 轻改 | 换词，摘掉最扎眼的腔调 | 不拆句、不动段；该整段删的列进建议删改清单 |
| 标准档（默认） | 句子和段落按含义整体改写，删多余的句子和段落 | 不调章节顺序和标题层级 |
| 重改 | 合并、重组段落，调章节顺序，大段删 | 不越保真线，不为了短和对仗压出新排比 |

**锁保护项。** 动手前把一个字都不能动的东西列出来：

1. 数字、日期、金额、版本号、百分比和它的基数
2. 命令、代码、路径、链接、配置项、字段名、错误码
3. 术语原词、产品名、人名、机构名、引语、书名、界面文字
4. 谓词的方向：谁对谁做了什么，因果谁在前（“压力大导致离职多”不能变成“离职多导致压力大”）
5. 效果和关系的类型：提升还是下降，相关还是因果，全部还是部分
6. 情态和强度：计划、预计、力争、可能、必须、应、可以、不做
7. 硬机制的描述：一个东西是怎么工作的，原文怎么说就怎么保
8. 证据和出处：论文结论、数据来源，不简化成“有研究发现”

## 2. 改写：从含义出发

1. 通读全文，写下（心里过也行）：这篇在讲什么，每段承担什么意思。
2. 站在全篇看：哪段可以整段删，哪几句在说同一件事，哪句的意思根本没立住。
3. 按任务尺度整体改写。能整段改就别抠单句；拆到单句是最后一步。
4. 用 [patterns.md](patterns.md) 的症状从大到小过一遍：结构、句子、词、标点、姿态。一段命中超过五处，整段按原意重写（轻改时列进建议删改清单）。
5. 补中文味：动词扛住句子没有？抽象的说法原文里有没有对应的具体？有没有喘不上气的长句？段末有没有在复述读者已经懂的话？
6. 手别太痒：每一处改动都说得出治的是什么毛病（哪条症状、哪句憋气、哪两句车轱辘、哪段可删）；说不出的，放回原样。

## 3. 三遍回读

三遍分开做，别合成一遍。

- **第一遍对账**：原文的每条信息在改写里有下落，改写的每条信息在原文或上下文里有出处。对着第 1 步的保护项一条条核。
- **第二遍抓残留**：有没有新长出来的腔调（同义换壳、假口语、新的排比），有没有漏掉的元话语、“不是 X 而是 Y”、机械编号。
- **第三遍读节奏**：念出来。憋气的长句补逗号；句子长短都一样的，调几句；句尾一串软绵绵的“的”“了”“呢”，收一收。只补停顿，别改成口语。

最后问三句：这篇的主线是什么？每一节都在替它说话吗？比改之前更清楚了吗？

## 4. 机器扫描

有 Go 环境时在 skill 目录里跑：

```bash
go run ./cmd/hhsh scan 稿子.md
go run ./cmd/hhsh check 原文.md 改稿.md
```

- `scan` 的半角标点命中要清到零（代码、英文原文、数字千分位、网址、文件名不算）。确实要留的，在修改报告里写明理由。
- `scan` 的其余三项（机械编号和量词标题、“不是 X 而是 Y”超过两处、元话语）和 `check` 的残留腔调只是候选：是有意的对比还是空心翻案，是文档索引还是机械编号，要人判断。拿不准的列进提醒，不自动改。
- 没有 Go 环境时，照第 6 节的清单手工过一遍。

## 5. 交付

- **正文**：能直接复制去用，前面不加引导语。
- **给作者的提醒**（有才附，最多三行）：原文缺的具体、有几种读法的句子、建议删但没删的整句、事实疑点。只写作者要处理的事，不复述正文，不解释改了哪里。
- **修改报告**（用户要，或者要一份能逐条审的修订稿时才出）：

```markdown
## 修改报告

- 场合和力度：（例：技术议论，标准档）
- 主要改动：（三到五条，每条写改了哪里、治的是什么毛病）
- 删掉的整句或整段：（原文位置 + 理由）
- 保护项核对：（数字、术语、承诺等逐项一致；如有改动写明）
- 扫描结果：（scan 各项命中数和处理结果）
- 给作者：（原文缺的具体、有几种读法的句子、建议删改清单）
```

## 6. 出稿前自检清单

- 保护项逐条对上了吗？改写里的每条信息都找得到出处吗？
- 每一处改动都说得出治的是什么毛病吗？
- 场合认对了吗？敬语、正式语气、该有的气势还在吗？
- 逐句回读：信息增减、数字条件、程度和范围词、主动被动、术语原词、语气档位，六项都等价吗？
- 结构排比扫过了吗？量词标题、分号串三连、“X 不 X”三连、多处对仗、凑三的名词串？
- “不是 X 而是 Y”的变体全文不超过两处吗？
- 元话语清干净了吗？中文正文里还有半角标点吗？
- 有没有自造新词？有没有装饰性的比喻、拿比喻代替推理？
- 动词和形容词配得上它的对象吗？
- 有没有车轱辘话、空过渡句、“铺垫、展开、小结”三段式？
- 有没有居高临下的宣称，或者讨好的客套？
- 标题过了 [titles.md](titles.md) 的要求吗？
- 念出来顺吗？有没有喘不上气的句子？
