## 接口概述

批量查询发票状态接口可以在一次请求中查询最多 50 张发票的最新状态，可用于财务对账。

该接口是幂等的，请求失败后可以重试，不会产生副作用。

请求方式：`POST /v1/invoices/batch-query`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| invoice_ids | string[] | 是 | 发票 ID 列表，最多 50 个 |
| include_items | boolean | 否 | 是否返回明细行，默认 false |

### 返回码

| 返回码 | 含义 |
|---|---|
| 200 | 查询成功（部分 ID 不存在时也返回 200，不存在的 ID 会出现在 `not_found` 字段中） |
| 400 | 参数错误，例如 invoice_ids 为空或超过 50 个 |
| 401 | 鉴权失败 |
| 429 | 请求过于频繁，单个 AppKey 每秒最多 20 次 |

### 注意事项

- 收到 429 时，建议使用指数退避重试。
- 已作废超过 180 天的发票不会返回。
