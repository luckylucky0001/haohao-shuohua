### 4.2 接口定义与数据模型

用户在 C 端选好门店、服务和时段后，通过下面的接口提交预约。

**创建预约**

`POST /api/v2/store/reservations`

本接口要做幂等，请求头 `X-Idempotency-Key` 必填：同一个幂等键在 24 小时内重复请求时，若请求体相同，则返回首次请求的结果；若请求体不同，则返回 40902。

请求示例：

```json
{
  "store_id": 30217,
  "service_id": 88,
  "slot_start": "2026-11-02T10:30:00+08:00",
  "party_size": 2,
  "contact_phone": "13800001234",
  "remark": "靠窗"
}
```

响应示例：

```json
{
  "reservation_id": "R202611020000173",
  "status": "PENDING_CONFIRM",
  "expire_at": "2026-11-02T09:45:00+08:00"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| store_id | int64 | 是 | 门店 ID |
| service_id | int64 | 是 | 服务项目 ID |
| slot_start | string | 是 | ISO 8601，带时区偏移，只能是整点或半点 |
| party_size | int | 是 | 1–20 |
| contact_phone | string | 是 | 入库存 AES 加密密文，查询接口只返回后四位 |
| remark | string | 否 | ≤ 200 字 |

门店在 15 分钟内未确认的预约，系统自动置为过期（status = 4）。

| 错误码 | 含义 |
|---|---|
| 40001 | 参数错误 |
| 40901 | 时段已满 |
| 40902 | 幂等键冲突 |
| 42901 | 触发限流（单用户 10 次/分钟） |
| 50001 | 内部错误 |

**数据模型**

```sql
CREATE TABLE store_reservation (
  id              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  reservation_id  VARCHAR(32)  NOT NULL,
  idempotency_key VARCHAR(64)  NOT NULL,
  user_id         BIGINT       NOT NULL,
  store_id        BIGINT       NOT NULL,
  service_id      BIGINT       NOT NULL,
  slot_start      DATETIME     NOT NULL,
  party_size      TINYINT      NOT NULL,
  contact_phone   VARBINARY(128) NOT NULL COMMENT 'AES 密文',
  remark          VARCHAR(200) DEFAULT NULL,
  status          TINYINT      NOT NULL DEFAULT 0 COMMENT '0 待确认 1 已确认 2 已取消 3 已核销 4 已过期',
  created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_idem_key (idempotency_key),
  KEY idx_store_slot (store_id, slot_start)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
