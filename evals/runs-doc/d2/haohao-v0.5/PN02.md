### 4.2 核销接口

`POST /api/v2/coupons/redeem`

请求头 `Idempotency-Key` 必填，取收银机流水号。同一个 key 24 小时内重复请求，直接返回第一次的结果，不重复扣券。

请求示例：

```json
{
  "coupon_code": "CP8F3K2Q",
  "store_id": "SH0217",
  "order_amount": 12800,
  "pos_txn_id": "POS20261021-000317"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| coupon_code | string | 是 | 券码 |
| store_id | string | 是 | 门店编号 |
| order_amount | int | 是 | 订单金额，单位分 |
| pos_txn_id | string | 是 | 收银流水号，与 Idempotency-Key 相同 |

响应：`discount_amount`（int，单位分）、`redeem_id`、`status`（`REDEEMED` / `REJECTED`）。

错误码：

| code | 含义 | 收银端处理 |
|---|---|---|
| 40901 | 券已核销 | 提示后按原价结账 |
| 40902 | 券已过期 | 同上 |
| 42201 | 订单金额未达门槛 | 同上 |
| 50301 | 券中心超时 | 走降级 |

收银端调用超时 800ms。超时或 50301 时先按原价结账，小票打印“优惠稍后返还”，差额由对账任务异步补偿（见 5.3）。

一单多券是否支持，等业务方确认；本期接口只接受单券。
