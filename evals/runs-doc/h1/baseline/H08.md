## 6. 数据指标与实验设计

本节说明“继续观看”模块上移实验的指标口径、分流与样本量、实验周期。实验用 A/B 对比验证模块上移对人均有效播放时长的影响，并用护栏指标限制它对首屏加载、新内容播放和客户端稳定性的副作用。

### 6.1 指标定义

| 类型 | 指标 | 口径 |
|---|---|---|
| 核心指标 | 人均有效播放时长 | 实验期内有效播放总时长 / 进组用户数；单次播放 ≥ 5 秒才计为有效播放 |
| 次要指标 | 继续观看模块点击率 | 模块点击 UV / 模块曝光 UV |
| 护栏指标 | 首页首屏加载时长 P90 | 实验组相对对照组增加不超过 100ms |
| 护栏指标 | 新内容播放占比 | 新内容（用户此前未看过的剧集）播放次数 / 总播放次数，下降不超过 2 个百分点 |
| 护栏指标 | 客户端崩溃率 | 不高于对照组 |

核心指标的分母是**进组用户数**，而不是 DAU，各方需严格对齐这一点。

### 6.2 分流与样本量

- 分流单位为用户 ID（uid），按 hash 分桶，实验 flag 为 `home_continue_watch_top`；
- 实验组 10%、对照组 10%，其余流量不进入实验；
- 按 MDE 相对提升 1.5%、α = 0.05、power = 0.8 估算，每组约需 42 万用户，按当前流量 7 天即可攒够样本；
- 新注册用户（注册 7 天内）是否进组，待和数据组对齐。

### 6.3 实验周期

实验周期定为 14 天，覆盖两个完整周末，用来平抑周内/周末差异和新奇效应的影响。实验期间不提前看数做决策：除非护栏指标被触发，否则不提前停止实验。任一护栏指标被触发时，由产品负责人决定是否提前关停。

### 6.4 不在本次实验范围

本次实验不评估对会员付费转化的影响，相关分析由会员团队另行安排。

待对齐：新注册用户是否进组（见 6.2），由数据组确认后补充。
