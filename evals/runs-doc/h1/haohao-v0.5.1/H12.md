# 风控规则 RC-117 灰度方案与回滚预案

负责人：孙浩 ｜ 状态：待评审

## 1. 背景与范围

1.1 规则：新设备登录后 24 小时内，单笔转账 ≥ 5000 元，需先通过人脸核验才放行。规则编号 RC-117。

1.2 shadow 结果：规则已在 shadow 模式（只记录不拦截）下跑了一周，时间为 10/12 到 10/18。命中笔数约占同期 5000 元及以上转账笔数的 0.8%。

1.3 范围：企业账户不在本次范围。

## 2. 灰度计划

2.1 分桶与档位：按用户 ID 尾号分桶，依次放量 1% → 10% → 50% → 100%，每档至少观察 48 小时。第一档定为 1%（曾有人提直接 5%，孙浩定先 1%，运营无异议）。

2.2 开始时间：计划 10/27 开 1%。

2.3 观察指标：

| 转账成功率 | 与没进灰度的用户比 |
| 相关客诉量 | — |

## 3. 回滚预案

3.1 回滚开关：配置项 `risk.rule.rc117.mode`，取值 `enforce` / `shadow`。改成 `shadow` 后 1 分钟内生效，不用发版。

3.2 触发条件：满足任一条即切 `shadow`。

| 指标 | 触发条件 |
|---|---|
| 转账成功率 | 比对照组低 1 个百分点以上 |
| 人脸核验接口 P99 | 超过 800ms，持续 10 分钟 |
| 误拦截客诉 | 一天超过 20 单 |

3.3 执行方式：触发后直接切 `shadow`，不用等审批，事后在群里同步。条件由孙浩确定。
