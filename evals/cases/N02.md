## 本地启动

需要 Go 1.22 以上和 Docker。

1. 复制配置：`cp config.example.yaml config.yaml`，把 `db.dsn` 改成你本机的数据库地址。
2. 启动依赖：`docker compose up -d mysql redis`。第一次拉镜像大概要 3 分钟。
3. 运行：`go run ./cmd/server`，默认监听 8080 端口。

如果启动时报 `dial tcp 127.0.0.1:3306: connect: connection refused`，多半是 MySQL 还没起来，等十几秒再试。
