## 接口概述

在企业财务数字化转型的大背景下，发票状态的实时掌握显得尤为重要。**批量查询发票状态接口**为您提供了一种强大、高效且灵活的方式，帮助您一站式获取多张发票的最新状态，全面赋能您的财务对账流程。

该接口允许您通过一次请求查询最多 50 张发票。值得注意的是，该接口是幂等的，这意味着您可以放心地进行重试，而无需担心任何副作用。

**请求方式**：`POST /v1/invoices/batch-query`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| invoice_ids | string[] | 是 | 发票 ID 列表，最多 50 个 |
| include_items | boolean | 否 | 是否返回明细行，默认 false |

### 返回码

| 返回码 | 含义 |
|---|---|
| 200 | 查询成功（部分 ID 不存在时也返回 200，不存在的 ID 会出现在 `not_found` 字段中） |
| 400 | 参数错误，例如 invoice_ids 为空或超过 50 个 |
| 401 | 鉴权失败 |
| 429 | 请求过于频繁，单个 AppKey 每秒最多 20 次 |

### 💡 温馨提示

为了确保您获得最佳的使用体验，我们强烈建议您在收到 429 时进行指数退避重试。需要特别指出的是，该接口**不会**返回已作废超过 180 天的发票。

通过合理使用本接口，相信您一定能够大幅提升财务对账效率，让数据真正为业务创造价值！
