# 🎉 v2.4.0 重磅更新！

我们很高兴地宣布，v2.4.0 正式发布！这不仅仅是一次版本迭代，更是我们对开发者体验的一次全面重塑。🚀

## ✨ 新特性

- 🔥 **全新重试机制**：`Client` 现已支持自动重试，默认最多重试 3 次，仅对网络错误和 5xx 生效，让您的调用稳如磐石。
- ⚡ **性能飞跃**：连接池复用逻辑经过深度优化，在我们的基准测试中，高并发场景下 P99 延迟降低约 30%。
- 🌈 新增 `WithTimeout` 选项，让超时配置前所未有地灵活。

## 🛠️ 问题修复

- 修复了在 Windows 上读取代理配置时可能出现的 panic（#412）。
- 修复了 `ListOrders` 分页在最后一页返回重复数据的问题（#398）。

## ⚠️ 破坏性变更

- `NewClient` 不再接受 `*http.Client` 作为第一个参数，请改用 `WithHTTPClient` 选项。

## 📢 废弃说明

- `SetRetry` 已被标记为废弃，但仍可正常使用，将在 v3.0 中移除。

感谢每一位贡献者的辛勤付出！让我们一起，构建更美好的开发者生态！💪
