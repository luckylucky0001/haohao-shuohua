## 2. 影响范围

- 时间：2026-10-14 20:05 至 20:47，持续 42 分钟；
- 范围：仅影响“今夜特价”频道的下单，普通预订链路未受影响；
- 超卖订单 137 单，涉及 23 家酒店。137 单占这 23 家酒店当晚同时段订单的 6.1%，占全平台同时段订单的 0.4%；
- 截至 10-16 18:00，已有 121 单完成改订或全额退款并补偿 50 元券，剩余 16 单仍在与酒店协商，预计 10-18 前处理完。

## 3. 根因分析

### 3.1 直接原因（已确认）
“今夜特价”频道的库存扣减先写 Redis、再异步落 MySQL。20:05 Redis 主节点发生主从切换，切换期间约 1.8 秒的写入未同步到新主节点，导致部分房型库存在 Redis 中被“回滚”到扣减前的数值，随后继续被售出。

### 3.2 深层原因（初步判断，待验证）
除了这次切换，还有两个环节，让超卖没有被及时发现或拦住：

- 异步落库的对账任务每 30 分钟才跑一次，无法及时发现 Redis 与 MySQL 的差异；
- 下单前没有以 MySQL 为准做最终校验。

第二点目前只是推测，等 10-23 的回放验证结果出来再定性。

### 3.3 非原因
此次事故与当天 19:30 的营销活动发布无关。活动流量峰值在 19:40 已回落，且活动入口不经过“今夜特价”频道。
